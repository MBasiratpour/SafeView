# SafeView

🌐 Project website: https://MBasiratpour.github.io/SafeView

> A safer internet experience — without censoring opinions.

SafeView is a browser add-on concept designed to protect users from
extremist, neo-Nazi, and far-right extremist propaganda, similar in
spirit to SafeSearch: instead of deleting content, it hides, blurs,
warns about, or blocks it depending on the user's settings — driven
by context, not just keyword matching.

## Structure

- `docs/` — the project landing page (served via GitHub Pages)
- `extension/` — the browser add-on (JS / HTML / CSS)
- `classifier/` — the Python text/image/context classification backend
